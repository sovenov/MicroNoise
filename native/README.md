# DSP helper

`dsp_accel.c` содержит только операции над переданными массивами: масштабирование,
усиление/клиппинг, преобразование float32/PCM16, сумму квадратов, пик и внутренний
цикл линейного ресемплера. Здесь нет шумоподавляющей модели, VAD, выделения памяти,
фоновых потоков, сетевых вызовов или изменяемого глобального состояния.

`noiseclean/dsp.py` задаёт ctypes-сигнатуры, проверяет версию ABI и типы буферов,
сохраняет ссылки на массивы на время вызова. При недоступной DLL работает прежний
Python-код. Переменная `MICRONOISE_PYTHON_DSP=1` принудительно выбирает его.

## Сборка

Нужен установленный MSVC x64; Python headers, Windows SDK и внешние пакеты
для этой DLL не требуются. Готовый бинарный файл включён в репозиторий.

```bat
py -3.8 tools/build_dsp.py
py -3.8 -m unittest discover -s tests -v
```

Компилятор ищется в PATH и стандартных каталогах Visual Studio. Можно задать
его явно: `py -3.8 tools/build_dsp.py --compiler "C:\path\to\x64\cl.exe"`.
После изменения C-кода нужно пересобрать DLL перед сборкой приложения.
Объекты/импортная библиотека сохраняются в `build/dsp`, результат —
`noiseclean/libs/dsp_accel.dll`.

Проверенный бинарник собран MSVC 14.44 x64, `/O2 /fp:strict /GS- /Zl`,
`/NODEFAULTLIB /ENTRY:DllMain /SUBSYSTEM:WINDOWS,6.01`; размер — 5632 байта.
В таблице импорта нет зависимостей, CRT не подключается. AVX не требуется.
Это сохраняет целевой формат Windows 7 x64; фактический запуск на Windows 7
в рамках этой проверки не выполнялся.

Арифметика использует double-промежуточные значения и явные float32-приведения
в тех же местах, что Python. Порядок умножений/сложений сохраняется, объединение
операций в FMA не включается. См. документацию MSVC:
[/fp:strict](https://learn.microsoft.com/en-us/cpp/build/reference/fp-specify-floating-point-behavior),
[/Zl](https://learn.microsoft.com/en-us/cpp/build/reference/zl-omit-default-library-name),
[/NODEFAULTLIB](https://learn.microsoft.com/en-us/cpp/build/reference/nodefaultlib-ignore-libraries).

`/GS-` используется только для этой DLL: у неё нет локальных массивов, копирования
строк, разбора файлов или выделения памяти. Размеры и указатели приходят от
проверяемых ctypes-обёрток. Индексы чтения ресемплера проверяются внутри C.

## Проверка и замеры

`tests/test_dsp.py` сравнивает нативный путь с Python: PCM16 на всём диапазоне,
округление float32, клиппинг, пустые/нечисловые значения, частоты 16–96 кГц,
состояние ресемплера и обработку настоящими Speex/RNNoise с VAD.
`tools/benchmark_dsp.py` проверяет хеши основного выхода, мониторинга и записи
до/после, чередует порядок запусков и считает медиану времени CPU.

```bat
py -3.8 tools/benchmark_dsp.py --output build/dsp-results.json
```

В `docs/dsp-performance-2026-10-23.json` сохранён замер против снимка кода
после оптимизации индикаторов и до переноса DSP-циклов в C: 3000 кадров (30 с),
3 повтора. SHA-256 исходных `engine.py` и `suppressors.py` указан в отчёте.
Все тесты используют синтетические данные; микрофон и кабель не открываются.
